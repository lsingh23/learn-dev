39. Modal

One boolean, one portal, three ways to close. The classic "do you know the DOM?" question.

The ask

Interviewer "Build a reusable Modal. A button opens it, it dims the page behind, and it closes on the X, on clicking the backdrop, and on Escape."

Parent owns a boolean. Modal renders nothing when it's false.

It should:

  • Open when the trigger is clicked.
  • Dim and cover the whole page.
  • Close on X, backdrop, and Escape.
  • Not close when you click inside.
  • Unmount its content when closed.
  • Lock body scroll while open.
  • Accept any children — reusable.

The mental model

The modal is a dumb component. It has no state at all. The parent holds one boolean and passes it down with a way to flip it back off.

The whole trick The overlay closes on click. The box sits inside the overlay, so a click on the box bubbles up to it. Stop that bubble and clicks inside are safe.

The shape of the state

// in the PARENT, not the modal
const [isOpen, setIsOpen] = useState(false); // the only state that exists

The modal takes props only:

<Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
  ...
</Modal>
Rule of thumb State lives with whoever decides. The parent decides when it opens, so the parent owns the boolean. That's also what makes the modal reusable.

Build it in layers

In the interview Build L1 and L2 out loud, get it opening and closing, then ask "want me to add Escape, portal and focus trap?" Don't start with a portal.

L1 Static markup, no state

Get the picture on screen. Styling barely matters — say that once and move on.

function Modal() {
  return (
    <div className="overlay">
      <div className="box">
        <button>✕</button>
        <h2>Delete account?</h2>
      </div>
    </div>
  );
}
/* the only CSS that matters */
.overlay { position: fixed; inset: 0; background: rgba(0,0,0,.5);
           display: flex; align-items: center; justify-content: center; }
.box     { background: #fff; border-radius: 10px; padding: 20px; }

L2 Open and close

Boolean in the parent; return null in the modal so it truly unmounts.

function Modal({ isOpen, onClose, children }) {
  if (!isOpen) return null;                      // unmounted, not hidden
  return (
    <div className="overlay" onClick={onClose}>  // backdrop click
      <div className="box" onClick={(e) => e.stopPropagation()}>
        <button onClick={onClose}>✕</button>
        {children}
      </div>
    </div>
  );
}
function App() {
  const [isOpen, setIsOpen] = useState(false);
  return (
    <>
      <button onClick={() => setIsOpen(true)}>Delete account</button>
      <Modal isOpen={isOpen} onClose={() => setIsOpen(false)}>
        <h2>Delete account?</h2>
      </Modal>
    </>
  );
}
stopPropagation — halt the bubble A click starts on the box and travels up through every ancestor, including the overlay. e.stopPropagation() ends that journey early.

L3 Escape key + body scroll lock

One effect, one cleanup. The cleanup is the part they're checking.

useEffect(() => {
  if (!isOpen) return;
  const onKey = (e) => { if (e.key === "Escape") onClose(); };
  document.addEventListener("keydown", onKey);
  document.body.style.overflow = "hidden";        // lock page scroll
  return () => {                                  // runs on close/unmount
    document.removeEventListener("keydown", onKey);
    document.body.style.overflow = "";
  };
}, [isOpen, onClose]);

Hooks can't sit behind an if, so the effect goes above the if (!isOpen) return null and bails inside itself.

L4 Portal — escape the parent's box

A modal rendered deep in the tree inherits its ancestors' overflow: hidden, transform and z-index stacking. It gets clipped or buried. A portal — render here, appear there — moves the DOM node to <body> while keeping React props and events.

import { createPortal } from "react-dom";

return createPortal(
  <div className="overlay" onClick={onClose}> ... </div>,
  document.body                                  // where the DOM node lands
);

L5 Accessibility — the layer that impresses

Announce it, trap the keyboard inside it, hand focus back when it closes.

<div className="box" role="dialog" aria-modal="true" aria-labelledby="t">
  <h2 id="t">Delete account?</h2>
const boxRef = useRef(null);          // a ref — a box that survives re-renders

useEffect(() => {
  if (!isOpen) return;
  const trigger = document.activeElement;        // who opened us
  boxRef.current?.focus();                       // move focus in (needs tabIndex={-1})
  return () => trigger?.focus();                 // give it back
}, [isOpen]);

Trap Tab: on the last element, wrap to the first.

const SEL = 'button, a[href], input, select, textarea, [tabindex]:not([tabindex="-1"])';

if (e.key === "Tab") {

The whole thing

import { useEffect, useRef } from "react";
import { createPortal } from "react-dom";

export function Modal({ isOpen, onClose, title, children }) {
  const boxRef = useRef(null);

  useEffect(() => {
    if (!isOpen) return;
    const trigger = document.activeElement;

    const onKey = (e) => {
      if (e.key === "Escape") return onClose();
      if (e.key !== "Tab") return;
      const els = boxRef.current.querySelectorAll(
        'button, a[href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
      );
      if (!els.length) return;
      const first = els[0], last = els[els.length - 1];
      if (e.shiftKey && document.activeElement === first) { last.focus();  e.preventDefault(); }
      else if (!e.shiftKey && document.activeElement === last) { first.focus(); e.preventDefault(); }
    };

    document.addEventListener("keydown", onKey);
    document.body.style.overflow = "hidden";
    boxRef.current?.focus();

    return () => {
      document.removeEventListener("keydown", onKey);
      document.body.style.overflow = "";
      trigger?.focus();
    };
  }, [isOpen, onClose]);

  if (!isOpen) return null;

  return createPortal(
    <div className="overlay" onClick={onClose}>
      <div
        className="box"
        ref={boxRef}
        tabIndex={-1}
        role="dialog"
        aria-modal="true"
        aria-labelledby="modal-title"
        onClick={(e) => e.stopPropagation()}
      >
        <button onClick={onClose} aria-label="Close">✕</button>
        <h2 id="modal-title">{title}</h2>
        {children}
      </div>
    </div>,
    document.body
  );
}

Gotchas

Hiding instead of unmounting. display:none keeps forms, timers and video playing. return null so it really goes away.
Forgetting stopPropagation. Every click inside the box bubbles to the overlay and closes the modal. Most common miss.
No cleanup on the keydown listener. Open/close ten times and you have ten listeners; Escape then fires onClose ten times. Always return the removeEventListener.
Modal owning its own isOpen. Then the parent can't open it. Boolean up, callback down.
Never restoring body.overflow. The page stays unscrollable forever after close. Also don't hard-code "auto" — reset to "" so the original stylesheet wins.

If they push

"Make it animate out." return null kills the exit animation. Keep it mounted one beat: track a isClosing flag, unmount on onTransitionEnd (or use a library).
"Two modals at once." Escape should close only the top one. Keep a module-level stack of open modals; on Escape, close the last. Same for restoring scroll — only unlock when the stack empties.
"Mouse-down on the box, mouse-up on the overlay." Dragging text out of the box fires click on the overlay and closes it. Close on the overlay only if e.target === e.currentTarget and the mousedown started there too.
"Do it without a portal." Render <Modal /> at the top level of the app, next to the router — no clipped ancestors to escape.
"What about <dialog>?" Native dialog.showModal() gives Escape, focus trap, top-layer and the backdrop free. Say you'd reach for it in real code; interviews usually want the manual version.

Say this out loud

  • "The modal holds no state — the parent owns one boolean and passes onClose down, so it's reusable."
  • "I'll return null when it's closed rather than hiding it, so the content actually unmounts."
  • "The overlay closes on click, and I stop propagation on the box so clicks inside don't bubble up."
  • "The Escape listener goes in an effect with a cleanup, otherwise listeners pile up on every open."
  • "I'm portalling to body so an ancestor with overflow hidden can't clip us."
  • "For a11y: role=dialog, aria-modal, focus moves in, Tab is trapped, and focus goes back to the trigger on close."
